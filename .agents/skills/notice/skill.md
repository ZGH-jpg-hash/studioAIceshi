# 通知撰写技能

## 使用场景
当用户要求撰写、修改或润色通知时使用此技能。

## 核心规则

### 1. 标题格式
- **绝对禁止**以"通知"二字开头
- 必须使用"XX部通知"的格式，例如：
  - 采购部通知
  - 宣传部通知
  - 销售部通知
  - 人事部通知
  - 财务部通知
  - 技术部通知
  - 等等

### 2. 部门判断
- 如果用户明确告知所在部门（如"我是销售部的"），使用该部门名称
- 如果用户没有告知所在部门，统一使用"XX部"作为前缀
- 示例：
  - 用户说"我是销售部的" → 标题使用"销售部通知"
  - 用户未提及部门 → 标题使用"XX部通知"

## 通知撰写要点

### 标准结构
1. **标题**：遵循"XX部通知"格式
2. **正文**：
   - 开头：说明通知的目的和背景
   - 主体：详细说明通知内容、时间、地点、要求等
   - 结尾：提出具体要求或注意事项
3. **落款**：
   - 部门名称
   - 日期

### 语言风格
- 正式、简洁、明确
- 避免使用口语化表达
- 重要信息要突出显示

## 示例

### 示例1：无部门信息
**用户请求**：帮我写一个五一节放假的通知

**输出**：
```
XX部通知

根据国家法定节假日安排，现将五一劳动节放假安排通知如下：

一、放假时间
2026年5月1日至5月5日放假调休，共5天。

二、注意事项
1. 请各部门提前做好工作安排
2. 放假期间请保持手机畅通
3. 注意出行安全

特此通知。

XX部
2026年4月27日
```

### 示例2：有部门信息
**用户请求**：我是销售部的，帮我写一个五一节放假的通知

**输出**：
```
销售部通知

根据国家法定节假日安排，现将五一劳动节放假安排通知如下：

一、放假时间
2026年5月1日至5月5日放假调休，共5天。

二、注意事项
1. 请各位销售人员提前与客户沟通，做好工作交接
2. 放假期间请保持手机畅通，及时响应客户需求
3. 注意出行安全

特此通知。

销售部
2026年4月27日
```

## 执行步骤
1. 分析用户请求，判断是否需要撰写/修改/润色通知
2. 识别用户是否提供了部门信息
3. 根据部门信息确定标题前缀（有部门用部门名，无部门用"XX部"）
4. 按照标准结构撰写通知内容
5. 确保标题符合"XX部通知"格式，不以"通知"开头
